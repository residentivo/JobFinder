Sistema de Busca Inteligente (Tipo LinkedIn Jobs)

Ideia de projeto
Criar um sistema de busca de vagas onde o usuário pode filtrar por:
● stack
● localização
● nível (junior/pleno/sênior)
● remoto/presencial
● salário

Tecnologias
● Next.js
● Typescript
● Elastic Search
● Tailwind

Diferencial
Adicionar:
● autocomplete
● ordenação inteligente
● filtros combinados
